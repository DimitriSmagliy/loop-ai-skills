Loop AI Skills

Six free, safe, single-purpose skills for Claude Code. One per video. No telemetry, no network calls, nothing destructive.

Get the free pack on GitHub

Install in one command

git clone https://github.com/DimitriSmagliy/loop-ai-skills && mkdir -p ~/.claude/skills && cp -r loop-ai-skills/plugin/skills/* ~/.claude/skills/

The six skills

/handoffWrite HANDOFF.md so a fresh session continues where you stopped.
/secret-guardScan for committed secrets and check settings.local.json is gitignored.
/ship-checkPre-commit checklist. Verdict: SHIP or FIX FIRST.
/explain-like-newExplain an unfamiliar repo and build a CODEMAP.md.
/deny-rulesMerge sensible deny rules into your settings, explained one by one.
/cost-saverFind where your context and tokens go, and trim them.

Read before you install

Every SKILL.md is short on purpose and lists its allowed-tools. Nothing runs commits, pushes, rm -rf, history rewrites or installs.
